# jps-ai-harness
AI Harness - SDD - TDD

Este repositorio va a contener un **Harness AI** para trabajar con agentes de inteligencia artificial.

El objetivo es proveer una estructura de trabajo (harness) que facilite el desarrollo, la orquestación y la evaluación de agentes de IA, apoyándose en metodologías como:

- **SDD** (Spec-Driven Development): desarrollo guiado por especificaciones.
- **TDD** (Test-Driven Development): desarrollo guiado por pruebas.
